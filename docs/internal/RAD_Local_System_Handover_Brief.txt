1.   What  you  are  building
RAD  Local  is  a  productised  website  channel:  custom-coded,  static-first  local-business  websites
built

fast

and

repeatably

for

regional

Australian

businesses

that

need

a

full

online

presence

from

scratch.

 These  are  not  WordPress  sites.  One  reusable  Astro  template  is  re-skinned  per  client  by  editing  a  small  set  of  design  tokens.   A  single  config  file  per  client  drives  the  technical  SEO  automatically.   A  single  config  flag  decides  whether  a  build  is  direct-client  (carries  a  “powered  by  Ready  Aim
Digital”

footer)

or

white-label

(the

partner’s

brand,

zero

RAD

references

in

the

delivered

output).
 Your  job  is  to  stand  the  system  up  and  prove  it  with  two  pilot  projects,  so  that  white-label  partner
clients

(already

being

marketed

to)

can

be

run

through

it

immediately

afterwards.
 The  headline  property  is  repeatability:  build  the  plumbing  once,  extract  a  section  library  from  the
first

real

then

compose

every

subsequent
